### H6

#### Valmistelut

**git clone** - uusi komento minulle, mutta kätevä, sillä saa kloonattua halutun kansion sisältöineen omalle koneelle. Tälla sai kerralla ladattua koko **tp-link-decrypt**-kansion sisällön omalle koneelle. 
  
    $ git clone https://github.com/robbins/tp-link-decrypt

Seuraavaksi latasin TapoV3-kameran binäärin **aws**-komennolla. Komentoa ei ensin löytynyt vaan se piti ensin asentaa. 

    $ sudo apt install awscli

    $ aws s3 cp s3://download.tplinkcloud.com/firmware/Tapo_C200v3_en_1.4.2_Build_250313_Rel.40499n_up_boot-signed_1747894968535.bin Tapo_C200v4_en_1.4.2.bin --no-sign-request

Lopuksi latasin vielä Moodle-sivulta löytyvän Tapo-kameran dump-tiedoston.

#### Asennustiedoston avaaminen

Aloitin tutkimalla tiedostoa yleisesti. Katsoin mitä kaikkea sieltä löytyi ja mihin tietoihin pääsi helposti käsiksi. Avasin dump-tiedoston Nano-editorissa, mutta se oli salattu ja sekavan näköinen. Myös strings-komento tuotti vain sekaisia merkkijonoja. 

**NANO KUVA**

Seuraava askel oli tutkia **binwalk**-komennolla mitä tapahtuu. Testasin **binwalk** ja **binwalk -B**- komennot. Tuloksena selkokielistä tekstiä josta selviää tietoja laitteiston arkkitehtuurista ja tiedostojärjestelmistä. Tiedostossa oli myös paljon pakattua dataa. 

**KUVA BINB**

Viimeiseltä riviltä löytyi vielä seuraava teksti joka kertoo että järjestelmästä löytyy Squashfs filesystem:
